# إعداد الإشعارات الداخلية

تم تطبيق ترحيل `user_notifications` بنجاح في قاعدة Supabase الفعلية بتاريخ 22 أغسطس 2026، مع تفعيل **Row Level Security** من لوحة Supabase.

يحتوي الجدول على مالك الإشعار، المشروع وتحديثه المرتبطين، النوع، العنوان، النص، وقت القراءة ووقت الإنشاء. تتعامل واجهة التطبيق معه عبر خادم MADD فقط، ولا يستخدم العميل وصولاً مباشراً للجدول.

> ملاحظة تطويرية: أداة قاعدة البيانات المحلية تتصل بمحرك TiDB، لذلك لا تصلح لتطبيق ترحيلات PostgreSQL الخاصة بـSupabase. مصدر الترحيل المعتمد محفوظ في `drizzle/0011_user_notifications.sql` وقد طُبّق من محرر SQL في Supabase.
