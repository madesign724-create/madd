# OAuth account-selection investigation

- Google OpenID Connect documents the standard authorization parameter `prompt=select_account` for asking the authorization server to show account selection: https://developers.google.com/identity/openid-connect/openid-connect
- The MADD application currently sends this parameter only to the intermediary Manus app-auth portal. The next implementation step is to send the portal-specific selection flag in addition to the standard parameter, so the intermediary preserves the user's account-selection intent when it begins the Google redirect.
