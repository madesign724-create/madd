# MADD Engineering & Finishes

تطبيق جوال عربي لإدارة رحلة عميل التشطيبات من تصفح الخدمات والكتالوج إلى إنشاء المشروع ومتابعة المراحل، مع لوحة تشغيل إدارية متكاملة لفريق **MADD Engineering & Finishes | ماد للهندسة والتشطيبات**.

## التشغيل المحلي

يتطلب المشروع Node.js 22 و`pnpm`. بعد الحصول على نسخة الكود، ثبّت الحزم ثم شغّل الخادمين معاً:

```bash
pnpm install
pnpm dev
```

تبدأ واجهة Expo عادة على المنفذ `8081`، وتعمل واجهة الخادم وtRPC على المنفذ `3000`. استخدم `pnpm check` لفحص TypeScript و`pnpm test` لتشغيل الاختبارات. لا تعدّل مخطط قاعدة البيانات يدوياً؛ أنشئ ترحيلاً عبر `pnpm db:push` بعد مراجعة ملف SQL الناتج.

## خريطة المشروع

| المسار | الغرض |
|---|---|
| `app/` | شاشات Expo Router للعميل والإدارة والتقارير. |
| `components/` | المكوّنات المشتركة وأدوات إدارة الكتالوج والشركة. |
| `server/routers.ts` | عقود tRPC والصلاحيات والتحقق من المدخلات. |
| `server/db.ts` | طبقة البيانات وقواعد الحوكمة والاستعلامات. |
| `drizzle/` | مخطط قاعدة البيانات والترحيلات المتسلسلة. |
| `lib/report-pdf.ts` | قالب التقرير الإداري وPDF. |
| `tests/` | اختبارات الصلاحيات والتقارير والتصدير. |
| `docs/` | مرجع التسليم والتشغيل والاستعداد للإطلاق. |

ابدأ بـ [المعمارية](docs/ARCHITECTURE_AR.md) لفهم تدفق البيانات، ثم [دليل الإدارة](docs/ADMIN_OPERATIONS_AR.md) للعمليات اليومية، و[اتفاقيات التطوير](docs/DEVELOPMENT_CONVENTIONS_AR.md) عند تنفيذ تغييرات، وأخيراً [قائمة ما قبل الإطلاق](docs/PRELAUNCH_CHECKLIST_AR.md) قبل إصدار تطبيق حقيقي.

## قواعد الصيانة

تُحفظ صلاحيات الإدارة في الخادم فقط؛ لا تعتمد على إخفاء زر في الواجهة كحماية. المنتجات المختارة من عميل لا تُحذف، بل تُخفى. عمليات نقل الملكية تتطلب تأكيداً نصياً صريحاً. لا تضع مفاتيح الخدمة أو كلمات المرور في الشيفرة أو في ملفات محفوظة داخل المستودع.
