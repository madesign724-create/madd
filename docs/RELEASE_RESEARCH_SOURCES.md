# مصادر بحث النشر

## Expo: بناء التطبيق لمتاجر التطبيقات

- المصدر: https://docs.expo.dev/deploy/build-project/
- تمت المراجعة: 2026-08-21 بتوقيت المستخدم.
- الخلاصة: تبنى نسخة الإنتاج عبر EAS أو بيئة بناء متوافقة؛ يوصي المصدر بملف AAB عند الإرسال إلى Google Play، بينما يمكن استخدام APK فقط للتثبيت المباشر الاختباري عند ضبط نوع البناء صراحةً. يلزم حساب Google Play Developer للنشر في Google Play وحساب Apple Developer Program للنشر في App Store. يجب تجهيز بيانات توقيع التطبيق قبل عملية البناء، ويمكن لـ EAS إدارة بيانات توقيع Android وiOS عبر خطواته التفاعلية.

## ملاحظة تطبيقية للمشروع

- لا تعتمد هذه المعلومة على حالة مشروع MADD وحدها؛ تُستخدم مع قائمة ما قبل الإطلاق ونتائج تدقيق الشيفرة قبل اتخاذ قرار النشر.

## Expo: إعداد الإشعارات الفورية

- المصدر: https://docs.expo.dev/push-notifications/push-notifications-setup/
- تمت المراجعة: 2026-08-21 بتوقيت المستخدم.
- الخلاصة: يحتاج تشغيل خدمة Expo Push إلى إعداد مكتبات الإشعارات ووظائف التعامل معها وبيانات اعتماد Android وiOS. توصي الوثائق باستخدام `projectId` ثابت عند تسجيل رمز Expo Push، وتوضح أن EAS Build يسهل ربط بيانات اعتماد الإشعارات مع مشروع EAS.
