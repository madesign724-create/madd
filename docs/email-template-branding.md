# تخصيص رسالة استعادة كلمة المرور

## النتيجة الحالية

قالب **Reset password** موجود في Supabase Authentication > Emails، لكن المشروع يستخدم مرسل البريد الافتراضي. تعرض لوحة Supabase تنبيهاً بأن تعديل عنوان الرسالة ومحتواها يتطلب إعداد **SMTP مخصص** أولاً.

## ما يلزم لإتمام تخصيص MADD

بعد ربط مزود SMTP باسم الشركة، يُضبط قالب Reset password ليحمل اسم MADD وشعارها والنص العربي، مع الإبقاء على متغير رابط الاسترداد الذي توفره Supabase.
