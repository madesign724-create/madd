# قائمة جاهزية MADD قبل الإطلاق

هذه القائمة عملية وتستخدم قبل نشر إصدار جديد. تُنفذ على نسخة اختبارية أولاً، ثم تحفظ نقطة استعادة قبل النشر.

## التحقق الوظيفي

- [ ] تجربة تسجيل العميل، إنشاء مشروع، اختيار خدمة ومنتج، وإرفاق ملف.
- [ ] تجربة دخول كل دور إداري والتأكد من غياب عمليات غير مصرح بها.
- [ ] نشر تحديث مشروع بصور والتحقق من ظهوره في خط العميل الزمني.
- [ ] اختبار إشعار دفع فعلي على جهاز iOS أو Android حقيقي.
- [ ] إنشاء تقرير شامل وتقرير تفصيلي وتصدير PDF ثم مشاركته من الهاتف.
- [ ] تعديل بيانات الشركة والشعار من إعدادات المالك ومراجعة انعكاسها في الصفحة والتقرير.
- [ ] تجربة نقل الملكية بحساب اختبار فقط ثم التحقق من السجل والصلاحيات.

## الجودة والأمان

- [ ] تشغيل `pnpm check` و`pnpm test` بنجاح.
- [ ] اختبار العربية واتجاه RTL والنصوص الطويلة على هاتف صغير وهاتف كبير.
- [ ] مراجعة كل صور الخدمات والمنتجات وحقوق استخدامها وصلاحية روابط التخزين.
- [ ] مراجعة الصلاحيات في الخادم وعدم الاكتفاء بإخفاء عناصر الواجهة.
- [ ] عدم وجود مفاتيح API أو عناوين داخلية أو بيانات شخصية في المستودع.
- [ ] تطبيق آخر ترحيلات قاعدة البيانات بعد أخذ نسخة احتياطية معتمدة.

## الإصدار والتشغيل

- [ ] تحديث رقم الإصدار والاسم والشعار في `app.config.ts` عند تغير الهوية الرسمية.
- [ ] إنشاء نقطة حفظ مع وصف واضح قبل النشر.
- [ ] النشر من زر **Publish** في واجهة المشروع بعد اكتمال نقطة الحفظ.
- [ ] اختبار حزمة الإصدار على أجهزة حقيقية، ثم تفعيل قنوات التوزيع المناسبة.

> لا تستخدم هذه القائمة كبديل عن سياسات الخصوصية أو المتطلبات القانونية المحلية؛ راجعها مع المختصين قبل الإطلاق العام.
