# دليل تشغيل إدارة MADD

## الدخول والأدوار

يسجل عضو الفريق دخوله بحسابه ثم يضيفه المالك من قسم الفريق ويحدد دوره. لا ينبغي مشاركة حساب المالك. يُستخدم المالك الاحتياطي لاستمرارية الوصول، بينما يجب تنفيذ نقل الملكية فقط عند تسليم مسؤولية التشغيل فعلياً.

| العملية | مكانها في الواجهة | النتيجة |
|---|---|---|
| إضافة/تعديل خدمة | لوحة الإدارة ← الكتالوج | تظهر صفحة خدمة قابلة للترتيب والنشر. |
| تنظيم التقسيمات والمنتجات | لوحة الإدارة ← الكتالوج | إضافة وتعديل وصور وسحب وإفلات وإخفاء آمن. |
| إدارة المشروعات | لوحة الإدارة ← المشروعات | تعيين مسؤول وتحديث الحالة ونسبة الإنجاز والمراحل. |
| إنشاء التقارير | لوحة الإدارة ← التقارير | تقرير شامل أو تفصيلي مع طباعة وتصدير PDF ومشاركة. |
| بيانات الشركة والحوكمة | لوحة الإدارة ← الفريق ← إعدادات الشركة والحوكمة | الشعار والنصوص وبيانات التواصل والملكية وسجل النشاط. |

## إدارة الكتالوج بأمان

استخدم **إخفاء المنتج** إذا كان قد اختاره عميل سابقاً أو قد تحتاج إلى استعادته لاحقاً. الحذف مخصص للبيانات غير المرتبطة فقط، وتتحقق الواجهة الخلفية من ذلك. احتفظ بالصور الواضحة والملكية، واستخدم ترتيب السحب والإفلات لتحديد أولوية العرض للعملاء.

## التقارير

التقارير إدارية فقط. يمكن فلترة التقرير الشامل بالنص والحالة ومسؤول المشروع والمدينة وفترة الإنشاء. ينتج زر **تصدير PDF** نسخة محلية أولاً؛ بعدها يفتح زر **مشاركة PDF** قائمة مشاركة الهاتف ليختار المستخدم واتساب أو البريد أو الملفات أو أي تطبيق متاح.

## الاستجابة لتحديثات المشروع

قبل نشر تحديث للعميل، راجع الحالة والنسبة والعنوان والصور. يصل إشعار دفع إلى أجهزة العميل المسجلة عند نجاح الإرسال. قد يفشل تسليم الإشعار إذا ألغى العميل الإذن أو لم يسجل جهازاً؛ يبقى التحديث محفوظاً داخل صفحة المشروع في كل الأحوال.

## الاستمرارية

راجع سجل النشاط دورياً، وعيّن مالكاً احتياطياً نشطاً. عند تغيير مسؤول التشغيل، نفذ نقل الملكية من الواجهة فقط واكتب نص التأكيد المطلوب. لا تحاول تعديل الأدوار مباشرة من قاعدة البيانات لأن هذه العملية تنظم تزامن دور المستخدم وعضوية الفريق وإعدادات الشركة.
