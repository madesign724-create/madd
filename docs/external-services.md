# خدمة البريد الداخلي لتقارير MADD

## Resend

تم اختيار Resend لإرسال التقرير الشهري الداخلي إلى بريد مالك التشغيل فقط بعد موافقة المستخدم. لا يُرسل التقرير إلى أصحاب المشروعات أو العملاء.

وفق صفحة التسعير الرسمية، تشمل الخطة المجانية **3,000 رسالة شهرياً** وبحد يومي قدره **100 رسالة**؛ وهذا يتجاوز احتياج التقرير الشهري الواحد.  [Resend Pricing](https://resend.com/pricing)

تذكر وثائق الأمن الرسمية وجود امتثال **SOC 2 Type II** و**GDPR**، وتشفير للبيانات المخزنة والمنقولة باستخدام **TLS 1.3 أو أعلى**. تحفظ مفاتيح API في متغيرات سرية على الخادم فقط.  [Resend Security](https://resend.com/docs/security)

## المتغيرات المطلوبة

- `RESEND_API_KEY`: مفتاح API من لوحة Resend.
- `MADD_REPORT_FROM`: عنوان إرسال موثّق في Resend، مثل `reports@yourdomain.com`.

المستلم الداخلي الثابت للتقرير المجدول هو `madesign724@gmail.com`.
