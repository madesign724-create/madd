## 1. نطاق السياسة

توضح هذه السياسة كيف تتعامل MADD مع البيانات عند استخدام تطبيقها وموقعها. وهي تنطبق على العملاء الذين يستعرضون خدمات التشطيبات أو ينشئون مشروعاً، وعلى أعضاء الفريق المخولين بإدارة المحتوى أو المشروعات.

## 2. البيانات التي نعالجها

| الفئة | أمثلة فعلية في MADD | سبب المعالجة |
|---|---|---|
| بيانات الحساب والاتصال | الاسم، البريد الإلكتروني، رقم الجوال، معرف الحساب | إنشاء الحساب وتسجيل الدخول والتواصل بشأن المشروع. |
| بيانات المشروع | العنوان، المدينة، نوع العقار، المساحة، ملاحظات المشروع، حالة المشروع ونسبة الإنجاز | إعداد الطلب وإدارة التنفيذ وعرض التقدم. |
| اختيارات التشطيب | الخدمات والتقسيمات والمنتجات والكميات والملاحظات | إعداد متطلبات المشروع والتقرير. |
| صور ومرفقات المستخدم | صور المشروع والملفات التي يرفعها العميل، وصور تحديثات المرحلة | فهم الطلب وتوثيق التقدم وعرضه للعميل. |
| الإشعارات | رمز إشعار الجهاز، حالة قراءة الإشعار | إرسال وعرض تحديثات المشروع عند منح المستخدم الإذن. |

## 3. الاستخدام والمشاركة

نستخدم البيانات لتشغيل الحساب والمشروع، وتأمين الخدمة، وتمكين فريق MADD المخول من متابعة الطلب، وإرسال الإشعارات التي يطلبها المستخدم. لا تبيع MADD البيانات الشخصية ولا تعرض إعلانات موجهة ولا تستخدم البيانات لتتبع المستخدمين عبر تطبيقات أو مواقع شركات أخرى.

نستخدم مزودين تقنيين لمعالجة البيانات بالنيابة عنا: **Supabase** للمصادقة وقاعدة البيانات، ومخزن الملفات المرتبط بالتطبيق للصور والمرفقات، و**Expo** لتسليم إشعارات المشروع. لا يُسمح لهؤلاء المزودين باستخدام بيانات MADD لأغراضهم التسويقية المستقلة.

## 4. الحماية والاحتفاظ

تُنقل البيانات عبر اتصالات مشفرة، وتُقيد صلاحيات فريق MADD بحسب الدور. نحتفظ بالبيانات ما دام الحساب أو المشروع نشطاً أو يلزم الاحتفاظ بها لتشغيل الخدمة. عند طلب حذف الحساب، نحذف أو نجهل البيانات المرتبطة خلال 30 يوماً، إلا إذا كان الاحتفاظ بجزء محدد مطلوباً قانوناً أو لازماً لتسوية التزام قائم؛ وسنوضح أي استثناء للمستخدم.

## 5. اختيارات المستخدم

يمكن للمستخدم تعديل الاسم ورقم الجوال من «حسابي»، وإيقاف إشعارات التطبيق من إعدادات الجهاز، وطلب حذف الحساب والبيانات المرتبطة به عبر صفحة `delete-account` أو بالبريد الإلكتروني المسجل. قد تطلب MADD تحققاً معقولاً من الهوية قبل الحذف لحماية الحساب من الطلبات غير المصرح بها.

## 6. الأطفال والتغييرات

الخدمة غير موجهة للأطفال. عند تعديل هذه السياسة أو طريقة استخدام البيانات بصورة جوهرية، سنحدّث تاريخ السريان في هذه الصفحة وننشر النسخة المحدّثة.
